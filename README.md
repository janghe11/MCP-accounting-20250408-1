## 왜 실패했는가?
1. 토큰 길이 이슈
1-1. 한번에 코딩 해 줄수 있는 토큰의 길이가 정해져있어, 코딩 도중 끊김.
1-2. 계속하기 지시를 해도, 최대 토큰 길이에 도달하여 새로 시작해야 함.
1-3. 새로 시작하여 이어 개발을 해달라고 하면, 기존 프로젝트를 다시 읽는데 토큰이 소요됨.

2. 일관성이 부족한 코드 품질
2-1. 새로운 채팅이 열릴 때마다 컨텍스트를 잃기 때문에, 어떨때는 학습 성취도에 집중하다가, 어떨때는 회계처리에 집중하는 등 중구난방으로 클래스가 생성 됨.
2-2. 없는 라이브러리를 생성하는 등 환각 현상도 발생함.
